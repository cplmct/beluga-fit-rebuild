TASK 4 — Update WorkoutChecklistScreen.tsx
After the personal_records upsert in doSaveWorkout,
add challenge progress update logic:

After saving a workout, fetch the user's active challenges
and update current_progress for each:

For 'consistency' and 'streak' type:
  Count workout_sessions WHERE user_id = user.id 
  AND status = 'completed'
  AND started_at >= uc.started_at 
  AND started_at <= uc.ends_at
  UPDATE user_challenges SET current_progress = count
  If current_progress >= target_value: SET status = 'completed', 
  completed_at = now()

For 'volume' type:
  Sum reps from session_sets WHERE exercise_id = challenge.target_exercise_id
  JOIN through session_exercises → workout_sessions
  WHERE started_at is within challenge period
  UPDATE user_challenges SET current_progress = sum
  If current_progress >= target_value: SET status = 'completed'

For 'duration' type:
  Sum duration_seconds / 60 from workout_sessions
  within challenge period
  UPDATE user_challenges SET current_progress = sum_minutes
  If current_progress >= target_value: SET status = 'completed'

For 'pr' type:
  Check if personal_records has a record WHERE exercise_id = 
  challenge.target_exercise_id AND achieved_at >= uc.started_at
  If yes: SET status = 'completed', current_progress = 1

Also mark expired challenges as failed:
  UPDATE user_challenges SET status = 'failed'
  WHERE user_id = user.id 
  AND status = 'active' 
  AND ends_at < now()
