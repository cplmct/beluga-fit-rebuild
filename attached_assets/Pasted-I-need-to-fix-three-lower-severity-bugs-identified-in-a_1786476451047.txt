BUG 2 — notifications.ts — Two fixes

BUG 2A — Timezone comparison for inactivity trigger:
PROBLEM: The check if (triggerDate <= new Date()) uses 
local Date comparison. triggerDate is built from a UTC 
ISO string — both sides of the comparison are actually 
UTC milliseconds under the hood via JS Date, so this 
is technically correct. However the comment and intent 
is clearer with explicit millisecond comparison.

FIX — Find: if (triggerDate <= new Date())
Replace with: if (triggerDate.getTime() <= Date.now())
This is semantically identical but explicitly UTC-safe 
and intention-clear.

Notifications.cancelAllScheduledNotificationsAsync() 
which cancels ALL scheduled notifications — including 
the inactivity reminder that was set up separately.

FIX — Find the scheduleDaily function.
Find where cancelAllScheduledNotificationsAsync is called.

Check if there is already a stored notification ID for 
the daily reminder. If so, cancel only that ID:

Replace:

With:
// Cancel only the daily reminder by identifier
