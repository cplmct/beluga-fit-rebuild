There is a critical bug in WorkoutChecklistScreen.tsx doSaveWorkout.

The exercises table was recently updated so all names are now Title Case
(e.g. "Squat", "Deadlift", "Bench Press") matching the static exercises.ts data.

THE BUG:
On line 363, allExerciseNames is built with .toLowerCase():
  const allExerciseNames = exercises.map((ex) => ex.name.toLowerCase());

This produces lowercase names like ["squat", "deadlift"].

On line 367, these lowercase names are used in a case-sensitive .in() query:
  .in('name', allExerciseNames)

Since the DB now has "Squat" not "squat", the query returns 0 rows.
nameToExId is empty. All exercises are silently dropped. Nothing saves.

THE FIX — two changes only:

Change 1 — Line 363: Use original names (NOT lowercased) for the DB query
BEFORE:
  const allExerciseNames = exercises.map((ex: ExerciseSelection) => ex.name.toLowerCase());
AFTER:
  const allExerciseNames = exercises.map((ex: ExerciseSelection) => ex.name);

Change 2 — Line 371: Use original name (NOT lowercased) as the key
BEFORE:
  nameToExId[row.name.toLowerCase()] = row.id;
AFTER:
  nameToExId[row.name] = row.id;
