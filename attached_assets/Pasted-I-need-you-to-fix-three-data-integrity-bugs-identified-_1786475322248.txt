BUG 1 — BodyTrackerScreen.tsx — Weight Unit Conversion

PROBLEM: In handleSave, weight is stored directly from the 
user's input without unit conversion. If the user has their 
unit preference set to lbs, the value is saved as lbs in the 
database but the field is meant to store KG. This corrupts 
body measurement data.

Same bug applies to the body measurement chart — if weight 
is stored in KG but user views in lbs, the chart shows 
wrong values.

FIX A — handleSave: Convert weight from display unit to KG 
before saving:
BEFORE: weight: weight ? parseFloat(weight) : null,
AFTER:  weight: weight ? parseFloat(weight) * (weightUnit === 'lbs' ? 0.453592 : 1) : null,

FIX B — prepareChartData for weight field only: Convert 
stored KG values to display unit for chart rendering.
After: const values = filtered.map((m) => m[field] as number);
Add: const displayValues = field === 'weight' 
  ? values.map(v => weightUnit === 'lbs' ? v * 2.20462 : v)
  : values;
Then use displayValues instead of values in the datasets.

FIX C — chartTitle for weight chart: 
BEFORE: Weight Trend ({weightUnit})
AFTER:  Weight Trend ({weightUnit}) — already correct, no change needed
